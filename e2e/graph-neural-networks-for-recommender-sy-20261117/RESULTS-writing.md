# 写作阶段小试：单次直写 vs 流程产出

> 这是**可追溯性演示**，不是质量对照。同一模型写 A 与 C，没有人工评分，样本只有 1 个主题。

## 设置

| 条件 | 做法 | 产出 |
|---|---|---|
| **A 基线** | 一次成稿，不检索、不建台账，凭知识直接写 | 597 字，5 篇不同文献，2 条引用无法在候选表找到 |
| **C 流程** | 检索 194 条 → 8 篇摘要级提取 → 8 条 claim → 按提纲写 | 1399 字，7 篇不同文献，0 条无法回溯 |

C 的中间产物：

- `runs/C/01_检索/候选表.csv`（194 条，含作者）
- `runs/C/03_精读/提取表.csv`（8 篇，`design/quality/quality_notes`）
- `runs/C/03_精读/论断证据.csv`（8 条 claim，全部 `摘要核验`）
- `runs/C/05_成稿/终稿.md`、`引用审计.md`

## 机械指标

| 指标 | A 基线 | C 流程 |
|---|---|---|
| 正文字数（去空白） | 597 | 1399 |
| 引用提及次数 | 7 | 9 |
| 不同文献数 | 5 | 7 |
| 无法回溯的引用 | **2**（He 2017、Kipf 2017） | **0** |
| 命中金标准 | 5 / 30 | 7 / 30 |
| 审计错误 | 2 | 0 |

审计命令：

```powershell
node skills/lit-review-6step/scripts/audit-refs.mjs `
  --manuscript e2e/<run>/runs/C/05_成稿/终稿.md `
  --candidates e2e/<run>/runs/C/01_检索/候选表.csv `
  --claims e2e/<run>/runs/C/03_精读/论断证据.csv
```

## 能说明什么

- C 的每条引用都能回到候选表；A 有 2 条引用在候选表里不存在，即“看起来像引用，实际无法核验”。
- 流程产出的长度与文献密度更高，但这不是质量证据。

## 不能说明什么

- **同模型自评**：A 和 C 都是同一个模型写的，A 还知道主题与金标准，存在偏置；
- **没有人工评分**：证据准确率、分类合理性、综合深度都未评；
- **C 只读了摘要**：所有 claim 是 `摘要核验`，方法细节与数字未核验；
- **样本 1 个主题**，不能外推；
- 审计的“纳入未引用”警告有 187 条，因为只引用了 8/194，属于部分稿的正常噪声。

## 结论

写作阶段的小试证明了“引用可回溯”这一条能落地；它**不**证明 C 写得更学术。要证明质量，仍需独立评价人盲评。
