# 自检清单

交付前逐项打勾；有一项不过就退回对应阶段。

## 结构

- [ ] 结构模式已选，理由与文献特征匹配（六种之一，不默认模式 A）
- [ ] 只用一套主维度
- [ ] 章节与分类一一对应（用模式 A 时：B 类数 = 章数、矩阵填满）
- [ ] 第 6 章挑战来自各章“未解决”

## 证据

- [ ] 每个强论断能指回 `03_精读/论断证据.csv` 的 `claim_id`
- [ ] 台账 `conditions` 无空值
- [ ] `摘要核验` 没有被用来支撑方法细节或实验数字
- [ ] `support=反对` 的证据进了冲突地图与正文

## 引用

- [ ] 抽 10 条引用回原文核对，全部对得上
- [ ] 参考文献与正文一一对应，无“文中无、表中有”

## 写作与审校

- [ ] 每章有 MR（导师审查）记录
- [ ] 每章有 CR-S 与 HLA-S 记录
- [ ] 摘要过 CR-S，且承诺的板块正文都有
- [ ] 自检清单为空或已说明

## 格式

- [ ] 标题层级一致，目录为自动生成
- [ ] 图表编号连续，正文有引用
- [ ] 引用格式全文统一（GB/T 7714 或 APA）
- [ ] 术语全文一致，缩写首次出现给全称
