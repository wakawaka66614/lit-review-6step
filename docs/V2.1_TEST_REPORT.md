## 失败与局限（必须一起读）

1. **审计仍是启发式**：只识别候选表里存在的 ID，任意未知前缀（如 `Z-1234`）无法发现；只能保证“表内可回溯”。
2. **作者-年份依赖 `authors` 字段**：字段为空时只警告，不报错；旧数据可能因此漏检。
3. **分类检查是结构代理**：单篇类别、来源单一不等于分类错误；学术合理性仍需盲评。
4. **覆盖矩阵靠人填**：`audit-coverage` 只查状态与数量是否矛盾，不判断方向是否真的重要。
5. **A/B/C/D 有选择偏差**：B/C 的 25 条按文件顺序截取，不是随机抽样；金标准是综述派生。
6. **写作小试同模型自评**：不能作为质量证据。
7. **未做**：专家金标准、盲评、人工修改比例。
