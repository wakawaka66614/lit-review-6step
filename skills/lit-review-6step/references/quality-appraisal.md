# 研究质量评价（Quality Appraisal）

## 原则

- **按研究设计选框架**，不搞全学科一张评分表；
- 评的是“结论有多可信”，不是“我喜不喜欢这篇”；
- 输出 **低 / 中 / 高 + 依据**，不折算成总分给论文排名；
- 质量低不等于排除——除非协议预先规定；它主要用于加权和解释冲突。

## 按设计选维度

| 设计 | 评价维度 |
|---|---|
| 定量（实验 / 准实验） | 样本代表性、对照组、测量效度、统计检验、偏倚来源 |
| 定性 | 抽样策略、资料收集、分析透明、反身性、可信度检验 |
| 混合方法 | 定量与定性部分分别评，再评“整合是否成立” |
| 计算机实验 | 数据集合理性、基线公平性、消融、可复现性、统计检验、代码/数据开放 |
| 综述 / 元分析 | 检索完整性、筛选透明、偏倚风险评估、异质性处理 |

领域内有成熟工具的优先用：RoB 2（随机试验）、ROBINS-I（非随机干预）、MMAT（混合方法）、CASP（质性）、AMSTAR 2（系统综述）。

## 三级评定

| 等级 | 含义 | 典型特征 |
|---|---|---|
| **高** | 主要维度都满足，结论稳健 | 有对照、有统计、可复现 |
| **中** | 有可识别弱点，但结论方向可信 | 单数据集、缺消融、样本有限 |
| **低** | 关键维度缺失，只能作参考 | 无对照、无统计、不可复现 |

每条给 1–2 句依据，写清“缺什么”，不写“质量一般”。

## 写进哪里

`03_精读/提取表.csv` 增加三列：

| 列 | 内容 |
|---|---|
| `design` | 实验 / 准实验 / 定性 / 混合 / 综述 / 计算实验 |
| `quality` | 高 / 中 / 低 |
| `quality_notes` | 依据，1–2 句 |

## 用在哪

- **冲突地图**：结论相反时，先看质量差异能不能解释；
- **第 6 章**：低质量证据扎堆的方向，就是研究挑战；
- **写作**：不许只写“某研究表明”，要能说出证据强度与适用条件。

## 边界

- 不用它给论文排“好坏榜”；
- 不因质量低自动排除（除非协议写明）；
- 评价人要在方法节交代用了什么框架、几个人评、分歧怎么处理。
