# 六阶段执行手册

每阶段开始先读对应子 skill 的 `SKILL.md`（路径见主文件依赖表），按它的工作流做，不凭记忆。每阶段结束把产物写进项目目录，再对照门禁自检。

---

## 入口契约（从 S2–S6 进）

从中间进入时，先校验"最小输入"，再登记"欠账"。缺项不要硬跑。

### S2（已有题目）

- **必须**：题目一句话；范围（学科 / 时间窗 / 语言，缺省可由 AI 提议并标注为假设）。
- **可选**：RQ、已有 5–10 篇文献。
- **动作**：写 RQ 卡（题目 / 一句 RQ / 概念块）→ 拆 PICO/SPIDER → 选库 → 出策略表。
- **校验**：RQ 含对象、机制、边界；概念块 ≥2；策略表 ≥3 行，每行有库和检索式。
- **欠账**：`入口=S2；欠账=缺口论证`。

### S3（已有检索式或指定库）

- **必须**：检索式清单，或"库 + 关键词 + 限定"。
- **动作**：先落策略表（哪怕 3 行），再执行、去重、初筛。
- **校验**：每行有库 / 式 / 限定；日志有检索日期。
- **欠账**：`入口=S3；欠账=检索策略的完整性`。

### S4（已有文献清单）

- **必须**：清单含标题、年份、来源（期刊 / 会议 / 预印本），并已标明纳入。
- **动作**：重建候选表——逐条分配 `paper_id`（P0001）、`source=manual`、`included=1`、`note=用户提供`；缺 DOI 的留空并在 note 标注；再进精读。
- **校验**：清单条数 = 候选表行数；`paper_id` 唯一。
- **欠账**：`入口=S4；欠账=PRISMA 计数与筛选透明度`。

### S5（已有提取表）

- **必须**：提取表含 `paper_id` 与至少 title / year / venue。
- **动作**：按 `paper_id` 反推候选表（`source=manual`、`included=1`）；提取表缺的题录从候选表补。
- **校验**：提取表 `paper_id` 唯一；候选表覆盖全部 `paper_id`。
- **欠账**：`入口=S5；欠账=筛选与检索记录`。

### S6（已有初稿）

- **必须**：初稿全文。
- **动作**：先抽引用建候选表（`channel=draft`、`included=1`）；再按 `survey-writing` §7 做结构诊断；最后才润色。
- **校验**：每条引用能在候选表找到，找不到标"待核"。
- **欠账**：`入口=S6；欠账=检索、筛选、提取链`。

### 欠账登记格式

写进 `00_选题/研究缺口与RQ.md` 顶部：

```text
入口：S2（用户已定题目）
跳过：S1 缺口分析
欠账：引言"现有综述总结"段（S5 补） / 方法节检索协议（S6 补）
```

## 每阶段结束：导师审查

进下一阶段前先跑 **MR**（规则见 `references/mentor-review.md`）：对照 `00_选题/主题契约.md`，只判断"还在回答同一个问题吗"。PASS 后再看本文件对应阶段的门禁。

| 阶段 | MR 只查 |
|---|---|
| S1 | 缺口是否支撑 RQ、模块是否都在范围内 |
| S2 | 概念块是否覆盖对象/机制/边界，有没有范围外概念 |
| S3 | 纳入文献是否服务 RQ，E1 是否被滥用 |
| S4 | relevance 能否指回章节 |
| S5 | taxonomy 是否回答 RQ、章节是否一一对应、有没有新增问题 |
| S6 | 终稿与摘要是否回答 RQ、结论是否超出证据 |

WARN 记录进 `00_选题/导师审查.md`；BLOCK 退回上一阶段，不靠写作补。

## S1 选题：从研究不足到研究问题

**读**：`literature-review-skills/skills/refine-literature-question/SKILL.md`、`.../locate-review-research-gap/SKILL.md`

**输入**：一个宽泛主题；已有的阅读/笔记（可为空）。

**动作**：把"前人没做什么"拆成三类，不要混着写——

| 类型 | 判据 | 例子 |
|---|---|---|
| 矛盾点 | 同一问题，结论相反或方向不一致 | A 说提升收益，B 说只对头部有效 |
| 空白点 | 该情境/人群/变量组合无人研究 | 都研究城市，没人研究县域 |
| 延伸点 | 结论成立但边界未测 | 只测短期，长期未知 |

**产物** `00_选题/研究缺口与RQ.md`：缺口陈述（≤200 字，每条断言标依据）→ RQ 一句话（对象 + 机制 + 边界）→ 3–5 个综述模块 → 可行性（可得文献量、数据可得性）。

**门禁**：没参与的人读完 RQ，能说出"你打算搜什么、不搜什么"；缺口陈述的每条断言都有出处或明确标注"待检索验证"。

## S2 策略：项目初始化与检索策略

**读**：`literature-review-skill/skills/文献检索/SKILL.md`

**动作**：
1. 先定综述类型（叙事 / 系统 / 范围 / 快速 / 引言 mini），据此选报告规范：系统综述 PRISMA 2020 + PRISMA-S；范围综述 PRISMA-ScR；叙事/课程综述不强制 PRISMA，但保留分阶段计数。
2. 按 PICO / PICOC / SPIDER 拆概念块，每块 3–8 个同义词，中英各一列；查 MeSH/主题词。
3. 选来源：**综合库 + 专业库 + 元数据 API + 引文追踪**四类。数据库按领域与 RQ 选，写清理由，**不设“几英几中”的数量门槛**。
4. 写检索式：**一个库一行**，语法不能跨库复制（WoS `TS=`、PubMed `[Title/Abstract]`、Scopus `TITLE-ABS-KEY`、CNKI `SU=`）。
5. 机器通道：AMiner（MCP）与 OpenAlex（`scripts/search-openalex.mjs`），见 `references/channels.md`；引文追踪用 OpenAlex 的前向/后向模式，或手工雪球。

**产物** `01_检索/检索策略表.md`、`01_检索/检索日志.md`、`01_检索/原始检索结果.csv`（去重前记录）。

**门禁**：每行都有库 / 检索式 / 限定 / 预计命中；四类来源都有覆盖说明；原始检索结果已保存。

## S3 检索与初筛

**执行**：
1. 按策略逐库检索，**每次检索的原始记录先写入 `01_检索/原始检索结果.csv`**（去重前），再进入候选表。
2. AMiner：每个查询取 2–3 页（10 条/页），`order=n_citation` 取奠基，`order=year` 取前沿；期刊定向用 `search_papers_by_venue`，核心作者用 `search_papers_by_author`。
3. 引文追踪：对 5–10 篇种子做前向/后向扩展（OpenAlex `--mode cited-by` / `--mode references`，或手工），记录种子、方向、工具、新增数。
4. 去重：DOI 优先；无 DOI 时标题归一化（小写、去标点、去空格）。
5. **分配主键**：去重后逐条分配 `paper_id`（P0001 递增），保留来源 `source` / `source_id` / `discovery`（哪条查询或哪次引文追踪发现），同一论文多来源时合并为一行、在 `note` 记来源链。
6. 分阶段筛选：题摘筛选（E1–E4）→ 全文获取（E6 未获取，单独计数）→ 资格评估（E7 违反预设标准）。
7. 统计 PRISMA 2020 分阶段计数，闭合校验见 `assets/search-log.md`。

**产物** `01_检索/原始检索结果.csv`、`01_检索/候选表.csv`、`02_筛选/筛选记录.md`。

**门禁**：每条 included=0 都有排除码 + 排除阶段；全文“未获取”与“资格排除”分开计数；四段闭合；系统综述走 `sr-screener` 双盲 + 第三仲裁，叙事/课程综述轻量筛选并抽 10% 复核。

## S4 精读与提取

**读**：`literature-review-skill/skills/文献精读/SKILL.md`

**动作**：Keshav 三遍法——第一遍 10 分钟判断值不值得读；第二遍抓论证结构与证据链；第三遍复现关键细节。笔记落 `03_精读/notes/`，结构化字段落 `03_精读/提取表.csv`。

**建台账**：把每篇的 `findings` 拆成可判断真假的论断，写入 `03_精读/论断证据.csv`（字段与规则见 `references/claim-evidence.md`）。一个论断一行证据；`conditions` 必填；`verification` 按四级标（全文 / 摘要 / 元数据 / 未核验）。

**评质量**：按 `references/quality-appraisal.md` 选对应设计的框架，在提取表填 `design`、`quality`、`quality_notes`、`appraisal_status`、`appraisal_confidence`。**摘要级阅读只能标记“未评价/部分完成/低置信”**，不能直接给高/中/低正式等级。

**覆盖审计**：填 `04_综合/覆盖矩阵.csv`（方向 / 重要性 / 经典 / 近期 / 全文 / 状态），跑 `scripts/audit-coverage.mjs`；核心方向不足就回 S3 补检索或 S4 补全文。规则见 `references/coverage-audit.md`。

**字段**：`paper_id` / 研究目的 / 方法 / 样本或数据 / 关键发现 / 局限 / 与 RQ 的关系 / 可引用原句 + 页码 / 设计类型 / 质量评级 / 评价状态与置信度。

**门禁**：候选表 `included=1` 的每一篇都有提取行；"局限"列为空的行退回重读；每篇至少贡献 1 条 claim；台账里没有空 `conditions`；质量评级与阅读深度一致（摘要级不得给正式等级）；覆盖矩阵核心方向不为“不足/待补充”。

## S5 综合写作

**读**：`literature-review-skill/skills/文献综述写作/SKILL.md` + `literature-review-skills/skills/map-literature-contradictions/SKILL.md`

**动作**：
0. **先选结构**：按 `references/survey-structure.md` 的结构选择器，从六种模式里选一个主导模式，写清理由、备选与放弃原因，记进提纲。模式 A（新技术×旧问题）只是其中一种。
0.5 **分类体检**：把分类写入 `04_综合/taxonomy.csv`（paper_id, category, subcategory, rationale），跑 `scripts/audit-taxonomy.mjs`，检查单篇类别、“其他”占比、类别来源单一、纳入未分类；不通过先调分类，不写正文。
1. 概念矩阵：行 = 纳入文献，列 = 概念（不是作者）。
2. **关系表**：按 `references/synthesis.md` 给同一主题的文献对判六种关系（一致 / 部分一致 / 冲突 / 方法差异 / 互补 / 无关），写入 `04_综合/文献关系表.csv`；只有“结论冲突”进冲突地图。
3. 列聚成 3–7 个主题；每组至少写一条 L3 及以上判断（关系 + 差异来源 + 解释 + 边界），不许停在“A 研究了…B 研究了…”。
4. 冲突地图：放 `relation_type=结论冲突` 的子集，先查质量差异，再查条件差异。
5. 逐段写作：**从论断台账取证据**，句子按“判断 → 证据 → 关系 → 解释 → 边界”组织；结尾 gap 段逐条挂回 RQ。
6. **出图（主题驱动，不用固定模板）**：
   - 先跑 `scripts/fig-plan.mjs`，从候选表 / 提取表 / 关系表 / 覆盖矩阵生成图表候选（`04_综合/图表计划.csv` + `data/`）；
   - 按主题增删：只保留能回答论点的图，补 `claim_id` 与结论式 `title`；规则见 `references/figure-planning.md`；
   - 统计图用 `scripts/fig-render.py` 一次性渲染 PDF + SVG + PNG；
   - 结构图 / taxonomy 总图 / 框架图才交 `nature-figure`（数据图不要用示意图冒充）；
   - 命名与存放：`04_综合/figures/Fig1_xxx.pdf|.svg|.png`，与图表计划编号一致。

**门禁**：
- 结构选择有理由，且与文献特征匹配；只用一套主维度；
- 每个主题至少 1 条 L3 关系判断；每条冲突有 `difference_source`；
- 综合性判断有 ≥2 条独立证据；文献间有差异时分析差异来源；定义与描述性段落不强制多篇；
- 每个强论断能指回 `claim_id`，且 `verification` 等级与论断强度匹配；
- 每个 gap 能指到 RQ 的哪一句；图表计划里的每张图要么已出图、要么注明不画。

## S6 统稿与格式

**读**：`literature-review-skill/skills/文献综述章节/SKILL.md`；引用核查调 `academic-paper` 的 citation-check 模式。

**动作**：逻辑链（问题 → 已知 → 争议 → 缺口 → RQ）→ 过渡句 → 术语与时态统一 → 格式统一（GB/T 7714 或 APA，全文一种）→ 引文与参考文献一一对应。

**核台账**：先跑 `audit-refs.mjs`（安装后在 `.dsh/skills/lit-review-6step/scripts/`），带 `--mapping 03_精读/段落证据映射.csv`，自动扫未知 `paper_id`、未纳入引用、作者年份、claim 核验等级与映射一致性，报告写入 `05_成稿/引用审计.md`；再人工抽查 10 条强论断，正文句子、`论断证据.csv` 行、原文三处对得上；检查 `conditions` 有没有被省略、`摘要核验` 有没有被用来支撑方法细节或数字、`support=反对` 的证据有没有进冲突地图。

**门禁**：Boote & Beile 12 条打分（博士 ≥18/24，硕士 ≥15/24）；随机抽 10 条引用回原文核对，错 1 条就全表复查；台账核验无“摘要核验撑数字”的情况。

## 常见失败模式

| 症状 | 根因 | 处理 |
|---|---|---|
| 综述写成读书笔记 | S5 按作者组织 | 回 S5 重排概念矩阵 |
| 检索"搜不全" | S2 概念块同义词不足 / 只搜一个库 | 回 S2 补同义词和库 |
| 筛到一半筛不下去 | 排除码不固定，标准漂移 | 回 S3 先定码再筛 |
| 写作时发现关键文献没读 | 候选表外引用 | 停写，回 S3 补录并重跑门禁 |
| 引用对不上 | 提取表没存页码 | 回 S4 补 quote + page |
