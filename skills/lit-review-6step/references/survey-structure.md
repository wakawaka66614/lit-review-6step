# 综述结构选择器

结构不是模板，是**从文献集合里归纳出来的组织方式**。先看文献长什么样，再选结构；不要先定结构再让文献往里塞。

## 三条原则

1. **分类从文献归纳**，不预设类别；
2. **一篇综述只用一套主维度**（与 `survey-writing` §3 一致），其他维度只能做辅助；
3. 结构决定“怎么组织”，不决定“必须几章”。

## 六种结构

| 模式 | 适用 | 主线 | 章节逻辑 | 主要风险 |
|---|---|---|---|---|
| **A 新技术 × 旧问题** | 成熟问题 + 新技术涌入 | B 技术分支 × A 问题分类 | 引言 / 背景（A、B）/ 交叉章 / 挑战 / 结论 | 为配对而制造分类 |
| **B 技术演进** | 技术快速迭代、代际明显 | 时间阶段 | 阶段 1…n（每阶段：突破、代表、局限） | 写成编年史 |
| **C 方法分类** | 方法数量爆炸、社区需要地图 | 方法机制 / pipeline | 通用框架 → 各类方法 → 比较 | taxonomy 立不住 |
| **D 问题导向** | 应用领域问题结构清晰 | 科学问题 | 问题 1…n（每问题：路径、方案、效果、边界） | 问题拆不细 |
| **E 跨学科视角** | 多学科研究同一对象 | 学科视角 | 视角 1…n → 理论差异 → 交叉融合 | 各说各话、缺整合 |
| **F 系统综述** | 有明确 PICO、可穷尽检索 | 证据链 | 方法 / 检索 / 结果 / 证据综合 / 偏倚 | 只报告不综合 |

评价与比较类可并入 C；以“评价维度”为主的，可用“维度 1…n → 方法对比 → 差异来源”。

## 怎么选

1. **看文献集特征**：时间跨度、方法数量、学科数量、问题数量、结论异质性。
2. **找主轴**：哪条线能把多数文献自然串起来？
3. **选一个主导模式**，其他模式只能借用局部写法，不能同时用两套主分类。
4. **写一句理由**：`本文按 ___ 组织，因为文献呈现 ___ 特征。`
5. **记进提纲**：主导模式、理由、备选模式、放弃其他模式的原因。

## 模式 A 细则（保留，作为可选之一）

### 七节骨架

| 章 | 内容 |
|---|---|
| 1 | 引言：大背景 → 小背景 → 现有综述总结 → 本综述特点 → 论文结构 |
| 2 | 背景知识 |
| 2.1 | 问题背景：旧问题 A 是什么 → a1…am |
| 2.2 | 新技术背景：B 是什么 → b1…bk → 末尾映射声明 |
| 3–5 | 第 i 章 = b_i × a_i：定义 → 问题面 → 代表工作 → 对比表 → 未解决 |
| 6 | 研究挑战与未来方向 |
| 7 | 结论 |

### 硬约束

- B 的类数 = 第 3 章起的章数；
- 2.2 末尾写映射（b1→第 3 章…），与章节号一致；
- B×A 交叉矩阵动笔前填满，空行/空列给解释；
- |A| ≠ |B| 时按 B 分章，章内覆盖相关 A 子集并说明。

### 门禁

| 门 | 检查 |
|---|---|
| G-A | 结构选择有理由，且与文献特征匹配 |
| G-B | 只用一套主维度 |
| G-C | 章节与分类一一对应（若用 A：B 类数 = 章数） |
| G-D | 矩阵/关系表填满（若用 A） |

## 通用要求（所有模式）

- 每章都有“定义与边界 → 证据 → 比较 → 未解决”；
- 第 6 章（挑战）从各章“未解决”里长出来；
- 结论回收分类体系，不引新文献；
- 结构选择写进提纲，图表计划与章节对应。

## 与模板的关系

`assets/survey-outline-pattern1.md` 是**模式 A** 的专用提纲模板；用其他模式时复制该文件，替换章节骨架与矩阵部分，保留“分类 + 章节细纲 + 图表计划 + 门禁”的结构。
