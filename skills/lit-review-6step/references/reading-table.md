# 精读记录表：按主题生成，不用固定模板

读之前先建表。表不是“读没读过”的清单，是**为写作准备的结构化证据库**：每篇文献沿同一组维度记录机制、证据、边界，读完能横向比较。

## 先定两件事

### 1. 梯队（读的优先级）

| 梯队 | 放什么 | 读法 |
|---|---|---|
| 第一梯队 | 核心理论 / 必读奠基 | 逐段精读，证据位置写页码 |
| 第二梯队 | 主要方法 / 直接竞品 | 读方法、实验、消融 |
| 第三梯队 | 评测、批判、相邻领域 | 读结论与局限，按需深入 |
| 第四梯队 | 背景理论 / 跨学科参照 | 只读能借用的机制 |

3–5 个梯队即可；不要按“年份”分梯队，按**阅读目的**分。

### 2. 维度（每篇都要回答的问题）

维度从 RQ 和综述类型长出来，不从模板抄：

- 机制类：对象是什么、如何寻址、何时触发、如何迁移/淘汰；
- 证据类：在什么数据上测、指标是什么、基线是否公平；
- 边界类：适用条件、失效场景、没解决什么；
- 写作类：这段能支撑哪条论断、和谁冲突。

6–9 个维度为宜。每个维度必须写清四件事：

1. `question`：要回答的问题；
2. `write`：至少写清什么（对象 + 机制 + 证据位置）；
3. `boundary`：最容易混淆的边界；
4. `analysis`：写完后用来分析什么。

**一篇综述只有一个精读表**；不同章节不要各建一套维度。

## 生成方式

写一份 JSON 规格，再渲染成 Excel：

```text
python scripts/make-reading-table.py --spec 阅读表规格.json --out 03_精读/精读记录表.xlsx
```

规格字段见 `assets/reading-table-spec.example.json`。生成的工作簿包含：

- 封面 / 使用说明 / 阅读框架
- 进度 / 总览
- 每个梯队一张表：表头 + 维度提问行 + 每篇一行（19 列左右）

## 填表规则

- 每格 2–4 句：机制 + 证据位置 + 边界；
- 证据位置写到页码/图表/章节，不写“见原文”；
- 填不出来就写“未报告”，不要留空；
- 读完一篇就填，不要攒到最后补。

## 与后续步骤的接口

| 表里的列 | 流向 |
|---|---|
| 九个维度 | 提取表的 `purpose/method/sample/findings/limitations` 与论断台账 |
| 维度提问 | 统计问题（`stat-questions`）与覆盖矩阵 |
| 梯队 | 阅读优先级，不进正文 |

## 反模式

- 维度全是“方法/结论/局限”三个泛列，读完无法比较；
- 每个梯队一套维度，横向对不齐；
- 表格只填“支持/不支持”，没有机制与证据位置；
- 表建了不填，最后还是靠笔记。
