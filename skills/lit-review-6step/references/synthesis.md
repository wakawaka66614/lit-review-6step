# 跨文献综合：从“并排”到“关系”

## 五个层次

| 层 | 特征 | 例子 |
|---|---|---|
| L1 并列 | 按主题分组，各说各的 | “A 研究了冷启动，B 研究了长尾” |
| L2 汇总 | 数数量、给趋势 | “多数方法集中在静态图” |
| L3 关系 | 判断一致 / 冲突 / 互补 | “A 与 B 结论相反，因为数据条件不同” |
| L4 机制 | 解释为什么 | “差异来自静态图无法建模兴趣漂移” |
| L5 边界 | 给出适用条件与缺口 | “只在冷启动成立，长尾未验证” |

写作目标：**正文至少到 L3，挑战章用 L4/L5**。停在 L1 就是流水账。

## 六种关系类型

| 类型 | 判据 | 怎么写 |
|---|---|---|
| 一致支持 | 结论同向、条件可比 | 合并成一个更强的判断 |
| 部分一致 | 同向但强度或范围不同 | 写清“哪部分一致、哪部分不一致” |
| 结论冲突 | 同条件下结论相反 | 进冲突地图，先查质量差异再查条件 |
| 方法差异 | 方法/数据不同，不能直接比胜负 | 不做“谁更好”的判断，写“各自能答什么” |
| 条件互补 | 不同场景下各自成立 | 合并成边界条件 |
| 对照但无关 | 主题相关但问题不同 | 只作背景，不与前者对撞 |

## 关系表

写入 `04_综合/文献关系表.csv`，一行一对关系：

| 字段 | 说明 |
|---|---|
| `relation_id` | R001 |
| `theme` | 所属主题 |
| `paper_a` / `claim_a` | 一方文献与论断（claim_id） |
| `paper_b` / `claim_b` | 另一方 |
| `relation_type` | 六种之一 |
| `difference_source` | 样本 / 测量 / 情境 / 时间 / 方法 / 质量 |
| `judgement` | 综合判断，一句 |
| `boundary` | 适用条件 |
| `quality_note` | 质量差异是否解释冲突 |

冲突地图只放 `relation_type=结论冲突` 的子集，不要另起一套。

## 五步写法

每段按这个骨架，不要写成“A 说……B 说……”：

1. **判断句**：这一组文献的关系是什么；
2. **证据**：`claim_id`，不堆作者名；
3. **差异来源**：样本 / 测量 / 情境 / 时间 / 方法 / 质量；
4. **解释**：为什么会出现这种关系；
5. **边界或启示**：这条综合成立的条件。

示例：

> 图方法在冷启动场景普遍优于序列模型（C001、C002），但这一优势只在静态图设定下成立：两项研究都没有建模兴趣漂移（C003），而引入动态图的工作报告了相反的长期效果（C004）。因此“图方法更好”应限定为短期、静态场景。

## 反模式

| 反模式 | 症状 | 修法 |
|---|---|---|
| 流水账 | 每段“A 研究了…B 研究了…” | 先写关系判断，再放证据 |
| 制造争议 | 为了凑“对撞”把不同问题的研究对立 | 用“对照但无关”，别硬比 |
| 方法差异当结论冲突 | 不同数据集/指标直接比高低 | 改判“方法差异”，写各自能答什么 |
| 忽略质量 | 结论相反时不看证据强度 | 先比质量，再比条件 |
| 只写“存在争议” | 没有差异来源 | 补样本/测量/情境/时间/方法/质量 |

## 与质量评价、冲突地图的关系

```text
论断台账（claim-evidence）
   ↓ 选同一主题的 claim
关系表（本文件）
   ├─ 结论冲突 → 冲突地图 → 查质量差异 → 查条件差异
   └─ 一致/互补/方法差异 → 直接进正文
```

## 门禁

- 每个主题至少有 1 条 L3 及以上判断；
- 每条“结论冲突”都有 `difference_source`；
- 正文里的关系句能指回 `relation_id` 与 `claim_id`；
- 不用“存在争议”“仍需研究”这类无信息量的句子收尾。
