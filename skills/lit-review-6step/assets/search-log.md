# 检索日志

## 一、检索协议（每个项目一份）

| 项 | 内容 |
|---|---|
| 综述类型 | 叙事 / 系统 / 范围 / 快速 / 引言 mini |
| 报告规范 | PRISMA 2020 + PRISMA-S / PRISMA-ScR / 不强制（叙事综述） |
| 数据库与平台 | 逐个列，不写“若干” |
| 检索式 | 原文，按库分别写 |
| 限定 | 年份、语言、文献类型 |
| 检索日期 | 每次检索的日期 |
| 命中数 | 每库每式 |

**报告规范按综述类型选**：系统综述用 PRISMA 2020 + PRISMA-S；范围综述用 PRISMA-ScR；叙事 / 课程综述不强制 PRISMA，但保留下面的分阶段计数。

## 二、原始检索结果

每次检索的原始记录保存到 `01_检索/原始检索结果.csv`（去重前的全部记录），不要只存最终候选表。否则无法复现检索过程。

## 三、PRISMA 2020 分阶段计数

| 阶段 | 数量 | 说明 |
|---|---|---|
| 数据库记录 |  | 各库命中合计 |
| 其他来源记录 |  | 引文追踪、灰色文献 |
| 去重移除 |  | E5 |
| 去重后 |  | 进入题摘筛选 |
| 题摘排除 |  | E1–E4，按码分列 |
| 全文获取 |  | 尝试获取的数量 |
| 未获取全文 |  | E6，**单独计数** |
| 资格评估 |  | 拿到全文并进入评估 |
| 资格排除 |  | E7，按码 / 标准分列 |
| 最终纳入 |  | included=1 |

**闭合校验**：

```text
数据库 + 其他 − 去重移除 = 去重后
去重后 − 题摘排除 = 全文获取
全文获取 − 未获取 = 资格评估
资格评估 − 资格排除 = 最终纳入
```
