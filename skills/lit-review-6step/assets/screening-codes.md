# 排除原因码

筛选分五段：**记录识别 → 去重 → 题摘筛选 → 全文获取 → 资格评估 → 纳入**。先定码、再筛；一条记录只选一个主码。

## 一、分段与可用码

| 阶段 | 可用码 | 说明 |
|---|---|---|
| 去重 | E5 | DOI 优先，其次标题归一化 |
| 题摘筛选 | E1 E2 E3 E4 | 只看标题摘要就能判断的 |
| 全文获取 | E6 | **未获取**，单独计数，不算资格排除 |
| 资格评估 | E7 | 不符合**检索前写定**的纳入标准 |

## 二、码表

| 码 | 含义 | 判据 | 典型误判 |
|---|---|---|---|
| E1 | 主题不符 | 研究对象 / 核心问题与 RQ 无关 | 只沾关键词，实际研究别的问题 |
| E2 | 类型不符 | 非同行评议、非研究性文本（社论、新闻、产品文档） | 把 arXiv 一律当正式发表 |
| E3 | 语言不符 | 不在团队可读语言内 | 标题机翻看不懂就排除 |
| E4 | 年份不符 | 超出协议时间窗 | 奠基文献被时间窗误杀——协议里要写例外 |
| E5 | 重复 | DOI 相同，或标题归一化后相同 | 预印本与正式版算两条 |
| E6 | 全文不可得 | 合规渠道都拿不到 | 没试过馆际互借就排除 |
| E7 | 资格不符 | 违反预设纳入标准中的某一条 | 把“方法不可比”当排除理由 |

## 三、E6 与 E7 的边界（重点）

- **E6 是“没拿到”，不是“不合格”**：单独计入“未获取全文”，不进入资格排除；后续拿到全文可以回到资格评估。
- **E7 是“拿到了但不满足预设标准”**：必须写明违反哪一条标准（如 `E7-c3` 指纳入标准第 3 条）。
- **异质性不是排除理由**：方法不同、结论相反、样本不可比，恰恰是综述要综合的内容；只有违反协议里预先写定的标准才排除。
- 协议里没写“方法不可比”，就不许用 E7 排除。

## 四、判定顺序

E5（重复）→ E1（主题）→ E2（类型）→ E3（语言）→ E4（年份）→ E6（未获取）→ E7（资格）。

## 五、复核

- 轻量筛选：随机抽 10%，第二人重筛，一致率 <90% 回炉重定标准；
- 系统综述：走 `sr-screener` 双盲 + 第三仲裁，报 kappa / PABAK；AI 只能做辅助，人工复核机制要写进方法节。

## 六、记录

每条 `included=0` 必须写：`exclude_code` + `exclude_stage`（去重 / 题摘 / 全文 / 资格）+ `note`；资格排除另写 `violated_criterion`。
